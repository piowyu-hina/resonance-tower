# 露咪的旅行商店

- 使用玩家更新的 `prototype/assets/characters/merchant_full.png`，不裁切、不重新產圖或程式去背。
- 桌面採大立繪與商品左右分區，暖棕、莓紅與奶油金配色；手機保留 350px 高角色展示區，商品接在下方。
- 商人對話不再蓋住人物；點立繪或對話框皆可聊天，鍵盤也可操作。
- 購買／出售使用頁籤，支援方向鍵、Home、End；長商品說明完整換行，價格與持有數分開顯示。
- 保留治療藥水、迅捷藥水、結晶單顆與全部出售、原價格、村莊／地城各自的金幣來源。
- 地城離店倒數在手機亦可見，聊天也會重設倒數，仍可手動關閉倒數；村莊商店沒有倒數。
- 本輪樣式集中於 `prototype/styles/shop.css`，沿用既有交易邏輯與 DOM 識別碼。
- 瀏覽器驗證：1440×1000、390×844、320×568、844×390，中英文版面、買賣、聊天、頁籤鍵盤操作、離店及地城倒數。

測試入口：Debug 預覽 `?debug&view=shop`，或從村莊點商店。
