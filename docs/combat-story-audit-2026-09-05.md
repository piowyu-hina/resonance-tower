# 首領進場與劇情版面檢查

## 本輪已修正

- 史萊姆王「召喚黏液」的 3 秒開場等待，以及「黏液陣」的 0.8 秒開場等待，原先共用施放後冷卻欄位。改為獨立的開場計時；未施放時技能圖示不顯示冷卻，原本出招節奏不變。
- 入場演出期間仍維持非戰鬥階段，技能、開場等待和生命值不推進。
- 清理黏液場地時同時清空開場及冷卻計時，避免離場後殘留。已有黏液批次時，不憑空重開一輪技能冷卻。
- 怪物 HP 已歸零但死亡旗標尚未結算時，不再攻擊、召喚或啟動首領小遊戲；角色也不再對零血目標浪費技能。
- 對話或事件暫停戰鬥時，黏液點擊一併鎖住；過期批次與死亡首領的黏液不再接受點擊。
- 開戰第一輪角色行動倒數與 UI 共用實際攻速計算，含暫時加速／減速，並同步第一輪週期長度。
- 放大一般劇情人物與女神立繪；全圖保持 contain，不裁切。視窗高度不足時讓人物區域縮小，對話文字保留可閱讀空間。

## 驗證範圍

- 單元測試：開場等待與真正冷卻、暫停、黏液場地清理、零血怪物出招防護。
- 瀏覽器：實際首領進場流程，演出期間狀態凍結、技能遮罩初始為零。
- 劇情版面：1440×1000、390×844、320×568、844×390；小初、無名與女神各自最長台詞，檢查人物和對話框邊界、橫向溢出及全圖顯示。
- 保留使用者自行整理的其他角色素材，不重新產圖、不改已確認劇情。

本次是戰前準備、戰鬥狀態與劇情顯示的針對性檢查，不代表所有未開放內容皆已完成驗證。
