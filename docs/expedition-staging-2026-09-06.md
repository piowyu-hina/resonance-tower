# 遠征準備專用背景

- 使用方式：內建 image_gen，未使用 API／CLI 備援流程。
- 圖檔：`prototype/assets/backgrounds/expedition-staging.png`，1536 × 1024。
- 參考圖：`prototype/assets/backgrounds/expedition-trail.png`，僅作畫風與世界觀參考，未替換入口原圖。
- 方向：保留使用者喜歡的近景氛圍，另畫林口整備位置，不再直接放大入口。正常遠征準備使用新圖；遺跡首領保留遺跡背景。
- 情報頁：保留既有暖金頁面、圖示分組與操作，只微調情報列間距與框線光感。
