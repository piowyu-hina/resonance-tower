# 璃雪語氣與史萊姆演出調整

## 本次基準

璃雪是膽小、可愛但願意靠近別人的女孩。她可以求助、怕痛、緊張，不用靠連續結巴表現每句話。遇險時，腳步與視線會先捕捉空檔；脫離危險後才察覺手在抖。這是有限的戰鬥直覺，不是老練劍士或指揮官。

## 劇本檢視

- 遺跡死亡：保留「不要……」「我還不想死……！」及傳送石被擊碎的既定因果，不加入新解釋。
- 女神：既有求生、縮肩、怕失去自己等反應已符合；把忘記儀式時的責備改成擔心回去後不知道怎麼辦。
- 手記：不改書中史實、誓言與契約規則。結尾由振奮出門口號改成先去近處、小聲安撫肚子，再檢查劍鞘、回望家裡。
- 初遇：保留小初提醒、第一次躲開、錯誤指揮被撞倒、自己抓落地空檔反擊。減少逼問和吐槽，改為驚慌、道謝、請對方走慢一點。名字揭露與 50 隻／清完當波的條件不變。
- 回家：璃雪怕招待不好，詢問椅子舒服嗎；請小初留意動靜，不以老師口吻分配工作。
- 契約：仍正視風險與彼此同意。璃雪坦承害怕，也不想讓小初再獨自等待；正式誓言原文不動。完成後喊小初，是怕她不見了。
- 日常三段：已包含猶豫、反覆檢查行囊、想多坐一下等個性，保留，不額外新增親密度門檻或篇章。停用的信任事件仍不接回目前流程。

正文來源：`prototype/js/story.js`、`prototype/js/xiaochu-story.js`。初遇 Markdown 與遊戲原文由測試比對；後續文件連結至原始劇本，避免第二份副本不同步。

## 演出

- 初遇缺圖是裁切問題：兩個角色原本是可捲動 `#dialogueBox` 的子元素，使用框外定位時被整塊裁掉。移為同層元素；對話文字仍可捲動。不能只以 Playwright 的 isVisible 判斷，現在另驗證祖先裁切範圍、圖片載入、畫布座標與演出結束隱藏。
- 史萊姆王沿用現有圖片，以 CSS 重作林間逼近、落地壓縮回彈、陰影／光暈／黏液飛濺、中央揭名。沒有新增生成圖，也不動遺跡之主。角色只用一條連續動作時間軸，避免進場與待機的 transform 爭用。
- 保留原本約 5.4 秒的受管理轉場與不可跳過規則；減少動態設定直接展示角色名稱，但仍維持流程鎖定。

## 預覽

正常 `index.html?debug` 的開發工具可播放新版小初初遇，或使用首領戰前測試查看史萊姆王。小初預覽不給予進度獎勵；實際流程仍須回村、回家談話、自願締約，演出完成才可使用小初。
