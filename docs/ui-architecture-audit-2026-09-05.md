# 2026-09-05 UI 與架構檢查

範圍：村莊、家、角色培養、角色詳情、區域、遠征準備、商店、物品庫、敗北、旅人手記、契約、對話、戰鬥、首領準備、事件。以 1440px 桌機與 390px 手機檢查；上述畫面未發現整頁橫向溢出或瀏覽器程式錯誤。未修改捲軸、玩家正在製作的圖片、角色框構圖或劇情正文。

## 本輪修正

- 戰鬥與 UI 共用實際主動技冷卻／角色行動間隔計算，主動強化後不再從半格冷卻遮罩開始。行動條以當次排定的週期計算，速度強化／加速／減速不再造成固定使用基礎間隔的顯示落差。
- 長按升級改用可取消的單一 timeout，初次升級便用完書不會再啟動計時器；鬆手、取消、切換視窗、頁面隱藏、按鈕移除與面板關閉都會終止。升級鎖定開始操作時的角色與強化項目，支援鍵盤單次操作。
- 培養面板新增技能「基礎效果」，與目前／下一級數值分開。格擋減傷與主動增傷顯示一位小數，避免相鄰級數被整數格式隱藏差異。
- 角色詳情的關閉鈕固定於捲動面板右上角，手機捲到技能升級區仍能直接關閉；不改捲軸樣式。
- 反擊就緒與斬擊強化改用可區別的「反」「斬」狀態標記，支援聚焦／鍵盤／點擊閱讀說明；睡眠、魅惑優先顯示，不被增益擠進更多狀態。
- 對話／事件暫停期間拒絕主動技與戰鬥物品；非目前出戰角色不能施放主動技。

## 驗證與產物

- `tests/ui-press.test.js`：資源耗盡、鬆手、失焦、隱藏、移除、dispose、鍵盤等長按生命週期。
- `tests/ui-regression.test.js`：升級後冷卻遮罩、加速行動條、操作狀態限制、狀態排序、技能說明、键盤升級與關閉面板停止消耗。
- `tests/ui-review.mjs`：檢查截圖存於忽略版控的 `.local/test-results/ui-review/`；`--skills-only` 可重拍本輪小初 UI。

## 暫不擴大處理

`state.js` 仍直接依賴劇情與 UI，`combat.js` 也仍呼叫部分劇情／介面協調器，模組依賴有繼續整理的空間。本輪只抽離長按生命週期、集中重複計算，不冒險一次重寫整個流程。既有故事可完整走到小初契約，因此先穩定現有操作，沒有追加支線或擅自改寫既定對話。

數值待後續試玩：目前純格擋強化線約第 42 級便達到 85% 減傷上限，之後不再增加減傷。本輪沒有擅改戰鬥平衡，之後可討論把 60%→85% 的收益分布到完整 100 級，或為後段提供其他收益。
